# Placeholders

All art is Godot `Polygon2D` / `_draw()` geometry.

- **Blue crystal** = player (left)
- **Red crystal** = enemy (right)
- Units keep a team tint (blue / red) plus a role accent: Rock, Fighting, Psychic, Fairy

Original stand-ins only: Cragback, Knuckhorn, Veilray, Gleamlet. Do not use Nintendo, Game Freak, or The Pokémon Company names or sprites.
