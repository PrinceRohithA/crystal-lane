# Placeholders

Geometric Godot `Polygon2D` / `_draw()` art is still compiled in as a **fallback** if a CC0 texture fails to load.

Shipped art lives under `assets/` (Kenney 1-Bit, MELLE crystals, Kenney Shape Characters, Kenney UI Pack). See `assets/ATTRIBUTION.md`.

- **Blue crystal** = player (LEFT) — MELLE `crystal_blue.png`
- **Red crystal** = enemy (RIGHT) — MELLE `crystal_red.png`
- Units keep a team tint (blue / red Shape Characters bodies) plus a role shape: square Tank/Rock, rhombus Melee/Fighting, circle Ranged/Psychic, squircle Support/Fairy

Original stand-ins only: Cragback, Knuckhorn, Veilray, Gleamlet. Do not use Nintendo, Game Freak, or The Pokémon Company names or sprites.
